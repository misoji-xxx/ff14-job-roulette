# FF14 ジョブルーレット仕様

## 概要

FF14の4人または8人パーティーにジョブをランダムで割り当てるWebアプリケーションです。GitHub Pagesでの公開を想定しています。

## モード

| モード | 機能 |
|--------|------|
| シンプル | 標準パーティー構成でロールとジョブを抽選 |
| 高機能 | プレイヤーごとのロール・除外ジョブと構成条件を指定して抽選 |

画面上のラジオボタンでモードとパーティー人数を選択します。初期状態はシンプルモード・4人です。

### 入力値と設定の保持

- 空欄のプレイヤー名は、抽選時に「プレイヤー1」からの連番へ置換します。
- シンプルモードの入力名はアプリケーション状態に保存しません。モードまたは人数を変更すると消去されます。
- 高機能モードの入力名・ロール・除外ジョブ・詳細設定は、4人用と8人用に分けてメモリ上へ保持します。
- ページを再読み込みすると、すべて初期状態へ戻ります。
- モード、人数、ロールを変更すると、表示中の抽選結果を消去します。

## シンプルモード

### パーティー構成

| 人数 | タンク | ヒーラー | DPS |
|------|--------|----------|-----|
| 4人 | 1 | 1 | 2 |
| 8人 | 2 | 2 | 4 |

構成内のロールをプレイヤーへランダムに配置し、各ロールに属するジョブを割り当てます。同一ジョブの重複は許可します。

## 高機能モード

### プレイヤー別ロール

| 人数 | 選択可能なロール |
|------|------------------|
| 4人 | タンク、ヒーラー、DPS、フリー |
| 8人 | タンク、ヒーラー、ピュアヒーラー、バリアヒーラー、DPS、メレー、レンジ、キャスター、フリー |

各プレイヤーの「ロール」ボタンから選択ダイアログを開きます。初期値は全員フリーです。

| ロール | 割り当て対象 |
|--------|--------------|
| タンク | タンク4ジョブ |
| ヒーラー | ピュアまたはバリアヒーラー |
| ピュアヒーラー | 白魔道士、占星術師 |
| バリアヒーラー | 学者、賢者 |
| DPS | メレー、レンジ、キャスター |
| メレー | メレーDPS |
| レンジ | レンジDPS |
| キャスター | キャスターDPS |
| フリー | 構成設定に従ってロールを決定 |

### 詳細設定

| 設定 | 初期値 | 動作 |
|------|--------|------|
| ジョブ重複禁止 | OFF | ONの場合、パーティー内で同一ジョブを使用しない |
| 標準構成を維持 | ON | 汎用枠を標準構成の不足ロールへ割り当てる |
| アライアンス構成を維持 | OFF | 8人の汎用枠を1T・2H・5DPSへ割り当てる |

「標準構成を維持」と「アライアンス構成を維持」は同時にONにできません。アライアンス構成は8人の場合のみ表示します。

#### 標準構成

| 人数 | 構成 |
|------|------|
| 4人 | 1T、1H、2DPS |
| 8人 | 2T、1ピュアH、1バリアH、2メレー、1レンジ、1キャスター |

8人の場合、次の順序で汎用枠を解決します。

1. ヒーラー枠を、不足するピュアまたはバリアへ割り当てます。
2. DPS枠を、不足するメレー、レンジ、キャスターへ割り当てます。
3. フリー枠を、残る不足ロールへ割り当てます。

固定枠が標準構成を超過する場合、標準構成の設定を無効化して「固定枠が超過」と表示します。

#### アライアンス構成

8人を1T・2H・5DPSへ解決します。ヒーラーのサブロールとDPSのサブロールはランダムです。固定枠が1T・2H・5DPSを超過する場合、この設定を無効化します。

#### 構成維持を使用しない場合

- 4人では、ヒーラー・DPS・フリー枠をタンク、ヒーラー、DPSからランダムに解決します。
- 8人では、ヒーラー枠をピュア・バリアから、DPS枠をメレー・レンジ・キャスターから、フリー枠を全サブロールからランダムに解決します。

#### 現実装上の制約

4人ではヒーラー・DPS・フリーを汎用枠として再解決します。そのため、ロールをヒーラーまたはDPSへ設定した場合でも固定指定にはならず、標準構成維持がONでも最終構成が標準構成から外れる場合があります。

### 除外ジョブ

- プレイヤーごとの「除外ジョブ」ボタンから設定ダイアログを開きます。
- 複数のジョブを選択できます。
- 保存するとボタンに除外件数を表示します。
- クリアはダイアログ内の選択を解除します。保存前に閉じた場合、変更を反映しません。

### 結果のロール表示

| 条件 | 表示 |
|------|------|
| シンプルモード | タンク、ヒーラー、DPS |
| 高機能モードの固定ロール | 選択したロール |
| 高機能モードの汎用枠・標準構成ON | 解決後のサブロール |
| 高機能モードの汎用枠・標準構成OFF | 解決後の基礎ロール |
| アライアンス構成ON | タンク、ヒーラー、DPS |

### 抽選エラー

除外設定またはジョブ重複禁止により割り当て可能なジョブがなくなった場合、結果の代わりにエラーメッセージを表示します。

## 結果

各プレイヤーについて、ジョブアイコン、プレイヤー名、ジョブ名、ロール、再抽選ボタンを表示します。

### 結果コピー

「結果をコピー」ボタンで、次の形式のテキストをクリップボードへ書き込みます。

```text
プレイヤー1: 💥ガンブレイカー
プレイヤー2: 🤍白魔道士
プレイヤー3: 👘侍
プレイヤー4: 🔥黒魔道士
```

- 1行を「プレイヤー名: 絵文字ジョブ名」の形式とします。
- ロールは含めません。
- 成功時はボタン文言を「コピーしました」へ変更し、2秒後に戻します。
- 失敗時はエラーメッセージを表示します。

### 再抽選

各結果の「再抽選」ボタンで、対象プレイヤーのジョブのみ再抽選します。

- 基礎ロールとサブロールを維持します。
- 高機能モードでは対象プレイヤーの除外ジョブを適用します。
- ジョブ重複禁止がONの場合、他プレイヤーが使用中のジョブを除外します。
- 候補がない場合はエラーメッセージを表示します。
- 再抽選では、現在割り当てられているジョブ自体を候補から除外しません。

## 技術仕様

| 項目 | 内容 |
|------|------|
| ビルド | Vite |
| 言語 | TypeScript |
| UI | バニラTypeScriptとネイティブHTML要素 |
| CSS | アプリケーション独自CSSなし |
| 状態管理 | クラスインスタンス内のメモリ状態 |
| データ永続化 | なし |
| テスト | Vitest |
| 配信パス | `/ff14-job-roulette/` |

### ファイル構成

```text
src/
├── main.ts
├── roulette.ts
├── roulette.test.ts
├── types.ts
├── data/
│   └── jobs.ts
└── components/
    ├── PlayerInputsRenderer.ts
    ├── ResultsRenderer.ts
    └── modals/
        ├── ExcludeJobModal.ts
        └── RoleModal.ts
```

| ファイル | 責務 |
|----------|------|
| `main.ts` | 状態管理、画面生成、イベント処理 |
| `roulette.ts` | 抽選、構成解決、再抽選 |
| `roulette.test.ts` | 抽選ロジックの単体テスト |
| `types.ts` | 高機能モードの型と初期値 |
| `data/jobs.ts` | ジョブ、ロール、ラベル、絵文字 |
| `components/*` | プレイヤー入力、結果、ダイアログのHTML生成 |

## テスト

```bash
npm test
npm run test:watch
```

単体テストは、標準構成、アライアンス構成、ジョブ重複禁止、除外ジョブ、再抽選を対象とします。
